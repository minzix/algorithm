### 뒤집은 소수
**설명**

- N개의 자연수가 입력되면 각 자연수를 뒤집은 후 그 뒤집은 수가 소수이면 그 소수를 출력하는 프로그램을 작성하세요.

- 예를 들어 32를 뒤집으면 23이고, 23은 소수이다. 그러면 23을 출력한다. 단 910를 뒤집으면 19로 숫자화 해야 한다.

- 첫 자리부터의 연속된 0은 무시한다.

**입력**

- 첫 줄에 자연수의 개수 N(3<=N<=100)이 주어지고, 그 다음 줄에 N개의 자연수가 주어진다.

- 각 자연수의 크기는 100,000를 넘지 않는다.


**출력**

- 첫 줄에 뒤집은 소수를 출력합니다. 출력순서는 입력된 순서대로 출력합니다.


_예시 입력 1_

```json
9
32 55 62 20 250 370 200 30 100
```

_예시 출력 1_

```json
23 2 73 2 3
```

**설명**

- 소수인지 여부 검사하는 함수
  - 소수란? 소수는 **1보다 큰 자연수 중**에서 1과 자기 자신만 약수로 가지는 수
- `2 ~ n의_제곱근`까지만 검사 하는 이유
  - `n = a * b` 에서 a, b 둘 다 n의 제곱근보다 크면 곱은 무조건 n보다 크기 때문에 둘 중에 하나는 무조건 n의 제곱근 이하이다
  - a, b 중 작은 수 기준으로 순회하며 나누어떨어지는지를 판별하자
  - `i * i <= n` 는 `i <= Math.sqrt(n)` 과 같으나, 반복문에서 `Math.sqrt` 를 매번 호출하는 것을 지양하기 위해 이렇게 씀
```java
public static boolean isPrime(int n) {
    if (n < 2) return false; // 0, 1, 음수는 소수가 아니다.
    for (int i = 2; i * i <= n; i++) { // 2 ~ n의 제곱근까지만 검사
        if (n % i == 0) return false; // i는 n의 약수 - n은 소수 아님
    }
    return true; // 2부터 제곱근 n까지 나누어떨어지는 수가 하나도 없었으므로 n은 소수
}
```
