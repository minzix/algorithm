### 소수(에라토스테네스 체)
**설명**

- 자연수 N이 입력되면 1부터 N까지의 소수의 개수를 출력하는 프로그램을 작성하세요.

- 만약 20이 입력되면 1부터 20까지의 소수는 2, 3, 5, 7, 11, 13, 17, 19로 총 8개입니다.


**입력**

- 첫 줄에 자연수의 개수 N(2<=N<=200,000)이 주어집니다.


**출력**

- 첫 줄에 소수의 개수를 출력합니다.


_예시 입력 1_

```json
20
```

_예시 출력 1_

```json
8
```

**설명**

1. 에라토스테네스의 체란? 
- 소수를 찾기 위해 배수들을 지워 나가는 방법
- 2부터 시작해서, 아직 지워지지 않은 수 𝑝 를 만나면 그것은 소수라고 보고, 그 𝑝 의 배수들 (`kp (k≥2)`)을 전부 지움

2. 배열의 기본형
- 배열을 처음 `new`로 생성하면 각 공간에 아래와 같은 디폴트 초기값들로 채워진다.

  | 배열 원소 기본값  | 해당 타입                                                        |
  | ---------- | ------------------------------------------------------------ |
  | `0`        | `byte[]`, `short[]`, `int[]`                                 |
  | `0L`       | `long[]`                                                     |
  | `0.0f`     | `float[]`                                                    |
  | `0.0`      | `double[]`                                                   |
  | `false`    | `boolean[]`                                                  |
  | `'\u0000'` | `char[]`                                                     |
  | `null`     | `String[]`, `Object[]`, `Integer[]`, `Double[]`, `Boolean[]` |

- 자바에서는 default 초기값을 수정할 수는 없음. 단, 아래와 같이 `Arrays.fill(배열, 원하는_초기값);` 으로 재할당하는 방법이 존재함. 
```java
import java.util.Arrays;

int[] arr = new int[5];
Arrays.fill(arr, 1);

String[] strArr = new String[5];
Arrays.fill(strArr, "");
```
